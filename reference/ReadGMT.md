# Read in a GMT file

Read in a GMT file

## Usage

``` r
ReadGMT(file_path = "", file_sep = ",")
```

## Arguments

- file_path:

  path to .gmt file

- file_sep:

  which delimiter is used to separate entries in .gmt file

## Value

Returns a data frame of the .gmt file terms and genes
