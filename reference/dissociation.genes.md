# Dissociation-associated gene signature

The human gene names of the dissociation-associated gene signatures from
the "Single-cell sequencing reveals dissociation-induced gene expression
in tissue subpopulations." van den Brink SC, et al. Nat Methods 2017.

## Usage

``` r
dissociation.genes
```

## Format

\## \`dissociation.genes\` A vector with 137 gene names:

- gene name:

  gene name
